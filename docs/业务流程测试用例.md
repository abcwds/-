# 宠物领养系统业务流程测试用例

## 1. 数据可信边界

系统中的品种知识、护理建议、品种体重范围和图片地址来自公开资料或公开 API：

| 来源 | 用途 | 地址 |
| --- | --- | --- |
| AKC Breed Info CSV | 犬种体重、寿命、性格、护理等级和简介 | https://raw.githubusercontent.com/tmfilho/akcdata/master/data/akc-data-latest.csv |
| Dog CEO Dog API | 犬只图片地址 | https://dog.ceo/api/breeds/list/all |
| The Cat API | 猫种资料和图片地址 | https://api.thecatapi.com/v1/breeds |
| MSD/Merck Veterinary Manual | 正常体温范围参考 | https://www.msdvetmanual.com/multimedia/table/normal-rectal-temperature-ranges |
| AAHA 2022 Canine Vaccination Guidelines | 犬疫苗接种参考 | https://www.aaha.org/resources/2022-aaha-canine-vaccination-guidelines/ |
| 2020 AAHA/AAFP Feline Vaccination Guidelines | 猫疫苗接种参考 | https://www.aaha.org/resources/2020-aahaaafp-feline-vaccination-guidelines/ |

数据库中的宠物年龄、性别、体重、毛色、救助站、健康记录和疫苗记录，是基于上述资料生成的**模拟业务数据**，用于演示和流程验证，不代表某个真实个体，也不替代兽医诊断。测试账号、领养申请和公告操作同样属于模拟数据。

可通过 `GET /api/system/data-sources` 查看系统当前登记的知识来源。

## 2. 固定账号

| 账号 | 密码 | 角色 | 用途 |
| --- | --- | --- | --- |
| `admin` | `123456` | 管理员 | 管理端登录和审核 |
| `user1` | `123456` | 普通用户 | 用户端浏览和领养 |

完整 smoke test 会创建带时间戳的临时普通用户，避免污染固定账号的历史记录。临时数据默认保留，便于审计；清理前请确认没有依赖这些申请记录的演示页面。

## 3. 核心测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | 服务健康检查 | 未登录访问 `/` 和 `/api/system/health` | 返回 `200`，并明确显示服务与数据库状态 |
| TC-02 | 管理员登录 | 使用 `admin/123456` 登录 | 返回 JWT，角色为管理员 |
| TC-03 | 普通用户越权 | 普通用户访问 `/api/admin/users` | 返回 HTTP `403` 和 JSON 权限提示 |
| TC-04 | 未登录访问 | 不带 Token 访问 `/api/auth/me` | 返回 HTTP `401` |
| TC-05 | 浏览宠物 | 访问 `/api/pets`，再访问宠物详情、健康和疫苗记录 | 返回可领养宠物及关联记录 |
| TC-06 | 提交领养申请 | 用户提交完整的姓名、手机号、地址、住房、经验和理由 | 返回 `200`，申请状态为待审核 |
| TC-07 | 重复申请 | 同一用户再次申请同一宠物 | 返回 `400`，提示已申请过 |
| TC-08 | 拒绝申请必须有理由 | 管理员用空理由拒绝待审核申请 | 返回 `400`，申请仍为待审核 |
| TC-09 | 拒绝申请 | 管理员填写明确拒绝理由 | 返回 `200`，申请状态变为拒绝，理由可查询 |
| TC-10 | 审核通过 | 管理员通过另一条待审核申请 | 申请变为通过，宠物变为已领养 |
| TC-11 | 同宠物并发申请 | 同一宠物存在两条待审核申请，管理员通过其中一条 | 通过的申请成功，其他待审核申请自动变为拒绝并写入系统理由 |
| TC-12 | 已领养宠物再次申请 | 宠物已领养后再次提交申请 | 返回 `400`，禁止重复领养 |
| TC-13 | 公告生命周期 | 管理员创建、发布、下架、删除公告 | 每次操作返回成功，用户端只展示已发布公告 |
| TC-14 | 数据来源追溯 | 访问 `/api/system/data-sources`，逐条检查名称和 URL | 返回登记来源，URL 可追溯到公开来源 |
| TC-15 | 数据库异常提示 | 停止数据库后访问健康检查 | 返回 `503`，状态为 `DEGRADED`，明确说明数据库不可用 |

## 4. 执行命令

在后端启动且 8080 端口可访问时执行：

```powershell
.\scripts\business-smoke-test.ps1
```

脚本会自动选择当前可领养宠物，创建临时账号，验证重复申请、拒绝理由、审核通过、同宠物冲突和已领养保护。
